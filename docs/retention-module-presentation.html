  • Driver also gets Google review CTA
  • Needs GOOGLE_CHAT_RETENTION_CELEBRATE_WEBHOOK_URL

Where Google Chat messages go

Messages go to whichever Google Chat Space you create the Incoming Webhook in (e.g. “Driver Wins” / Retention). There is no hardcoded channel name in the app.

1Open or create a Google Chat Space for celebrations.
2Space menu → Apps & integrations → Incoming webhooks → Add.
3Name it (e.g. Retention Celebrate) → copy the webhook URL.
4Set env GOOGLE_CHAT_RETENTION_CELEBRATE_WEBHOOK_URL → redeploy.
